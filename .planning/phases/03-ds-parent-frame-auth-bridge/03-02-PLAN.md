<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Parent window ↔ DS iframe | `postMessage` structured-clone payloads (no cookies) |
| Iframe bridge → Leaflet | `createTile` / `done` — must not throw into DS adapter |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T03-02-01 | Spoofing | Inbound `tile-result` | mitigate | `event.origin === _SPLUNK_ORIGIN` exact equality (D-NN-4); Jest negative matrix. |
| T03-02-02 | Tampering | Malformed tile URL | mitigate | Optional `PROXY_URL_SHAPE.test(url)` before postMessage (same export as parent, D-04). |
| T03-02-03 | Info disclosure | Request/response bodies | mitigate | D-NN-3 key sets only; Jest `JSON.stringify` must not contain `cookie`, `session`, `token`, `csrf`, `password` substrings on fixtures. |
| T03-02-04 | DoS | Timers / in-flight work | mitigate | D-06 cap + timeout; `removeEventListener` in `onRemove`; D-03 revoke on both img paths. |
| T03-02-05 | Elevation | Upstream tile hosts | inherit | Phase 1 SSRF (`01-SECURITY.md`); D-NN-5 no client allow-list duplication. |
| T03-02-06 | Tampering | Rogue `type` literals | mitigate | Iframe only handles inbound `maps-plus:tile-result` for tile bytes; outbound only `maps-plus:fetch-tile` (D-NN-2). |
</threat_model>
