<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DS iframe → Splunk REST | Attacker-controlled `url`, `z`, `x`, `y`, `s`, `r` query params cross untrusted→trusted at `handle_GET` entry |
| Splunk process → upstream CDN | Handler's outbound `urllib.request.urlopen` crosses internal→external; SSRF risk if destination is attacker-chosen |
| Upstream response → Splunk process | Attacker-controlled bytes cross external→internal; response-size risk |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T1-01-SSRF | Tampering / InfoDisclosure | `_fetch_tile` call site | mitigate | 4-layer validation in `_validate_url` BEFORE any urlopen: (a) `urlparse(url).scheme == 'https'` only (D-09); (b) host allowlist via leftmost-wildcard match against `allowed_domains` (D-01/D-02/D-03); (c) reject `@ # .. \\n \\r \\x00 %00 %0a %0d` in URL; (d) `socket.getaddrinfo()` then reject any IP where `ipaddress.ip_address(ip)` is loopback/private/link_local/reserved/multicast OR equals `169.254.169.254` — addresses audit A-01 |
| T1-02-InjectionZXY | Tampering | `_resolve_tile` | mitigate | Parse z/x/y as non-negative int; reject raw string containing injection chars before substitution; raise ValueError → caller returns 400 |
| T1-03-ResponseSize | DoS | `_fetch_tile` | mitigate | `resp.read(MAX_TILE_BYTES + 1)`; if len > 512KB raise ValueError('upstream_response_too_large') — addresses audit A-03 (the real A-03 about response size) |
| T1-04-Redirect | Tampering | `_fetch_tile` opener | mitigate | Module-level `_opener = build_opener(_NoRedirectHandler())` so all 3xx responses become errors — prevents allowlisted host redirecting to internal IP (Pitfall 4) |
| T1-05-CachePoisoning | Tampering | cache-key construction | mitigate | `hashlib.sha256(normalized_url).hexdigest()` full 64 hex chars (no truncation, A-11); keys are opaque so traversal chars in URL cannot escape cache dir |
| T1-07-RateLimitAmp | DoS | upstream providers | accept | Per-session rate limiting deferred (D-05/D-06). Mitigated indirectly by LRU cache reducing upstream load |
| T1-08-UnauthAccess | Spoofing | REST endpoint surface | mitigate | `requireAuthentication = true` is Splunk default; Plan 1.2 sets it explicitly in restmap.conf. Handler does NOT bypass session check |
| T1-09-Disabled | Misuse | `handle_GET` entry | mitigate | First line of `handle_GET`: if `_load_settings()["enabled"] is False`, call `self.response.setStatus(503)` + write `{"error":"proxy_disabled"}` — addresses audit A-09 |
| T1-10-BinaryEncoding | Integrity | response write | mitigate | Pass `bytes` returned by `resp.read()` DIRECTLY to `self.response.write()`; never `str(data)` (Pitfall 2) |
| T1-11-ErrorLeak | InfoDisclosure | exception handlers | mitigate | All error responses body = `{"error":"<short_code>"}` only. Never serialize traceback, upstream body, or exception str (D-13) |

    ```python
    def _resolve_tile(template, z, x, y, s=DEFAULT_SUBDOMAIN, r=DEFAULT_PIXEL_RATIO):
        # Coerce z/x/y to non-negative int
        for name, val in (("z", z), ("x", x), ("y", y)):
            sv = str(val)
            for bad in _INJECTION_CHARS:
                if bad in sv:
                    raise ValueError("invalid_chars_in_" + name)
            try:
                iv = int(sv)
            except (TypeError, ValueError):
                raise ValueError("not_integer_" + name)
            if iv < 0:
                raise ValueError("negative_" + name)
        # Literal substitution only — NO auto-swap of {x} and {y} (audit A-07)
        resolved = (template
                    .replace("{z}", str(int(z)))
                    .replace("{x}", str(int(x)))
                    .replace("{y}", str(int(y)))
                    .replace("{s}", str(s) if s else DEFAULT_SUBDOMAIN)
                    .replace("{r}", str(r) if r else DEFAULT_PIXEL_RATIO))
        return resolved
    ```

    ```python
    def _make_cache_key(resolved_url):
        p = urllib.parse.urlparse(resolved_url)
        normalized = urllib.parse.urlunparse((
            p.scheme.lower(), p.netloc.lower(), p.path,
            p.params, p.query, ""))
    ```
