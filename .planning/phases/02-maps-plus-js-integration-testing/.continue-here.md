## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Embedded PAT in git remote URL | The `github` remote URL contained `https://ghp_...@github.com/...` and was visible to anyone running `git remote -v` (including AI sessions, terminal recordings, screen shares). The token has been removed from git config and stored in macOS Keychain via `osxkeychain` helper. **The token still needs to be rotated** at https://github.com/settings/tokens before bringing up the new MacBook. | blocking | When configuring the new MacBook, use `gh auth login` (preferred) OR set up SSH keys — do NOT recreate the embedded-token URL. The bootstrap prompt at `.planning/NEW-MACHINE-BOOTSTRAP.md` covers both options. |
| `cd` inside Shell tool persists across calls | The Shell tool keeps cwd between invocations. A bare `cd appserver/...` followed by another `cd appserver/...` causes `appserver/appserver/...` errors. | advisory | Use absolute paths or `cd /Users/Shaskell/...` at the start of each Shell call. |
| `gsd-sdk` CLI not installed | The GSD SDK binary is not available in this environment. Workflows that depend on it (e.g. `gsd-sdk query init verify-work`) silently degrade. | advisory | Run workflows in sequential-inline mode and rely on direct file inspection. The new MacBook setup includes installing the GSD SDK if available — see bootstrap prompt step 7. |
